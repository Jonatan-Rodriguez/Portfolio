# Portfolio — Jonatan Rodriguez

Stack: Vite + React + TypeScript + Tailwind CSS + Framer Motion.

## Instalar y correr

npm install
npm run dev

## Que esta hecho

- Header fijo con nav pill, se pega arriba al hacer scroll, barra de progreso de lectura en el top.
- Toggle de tema claro/oscuro (icono en el nav + el switch grande decorativo del hero), persiste en localStorage.
- Boton de idioma EN/JA (visual, todavia no traduce contenido).
- Fondo tipo hoja cuadriculada con textura de grano sutil, en beige claro (#fffcf3) y negro en modo oscuro.
- Hero: "Full-Stack" / "DEVELOPER" / "PERN", con la foto que al pasar el mouse revela una segunda imagen solo bajo el cursor (efecto linterna) y el nombre que se disuelve letra por letra a otro texto.
- Secciones About, Proyectos y Experience creadas como placeholders con su ancla, listas para ir llenando.
